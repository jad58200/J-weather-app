# 🌦️ React Weather App

A responsive weather application built with React that provides real-time weather data for any city. It features a clean interface, dynamic UI updates, and accurate weather information sourced from a public API.

---

# 🚀 Features

- Built with React and functional components  
- Real-time weather search by city name  
- Displays temperature, humidity, wind speed, and weather conditions  
- Clean, modern, and mobile-friendly user interface  
- Uses React hooks for state and effect management  
- Fast and efficient API integration

---

# 🛠️ Technologies Used

- React  
- JavaScript (ES6+)  
- CSS3  
- Fetch API / Axios  
- Vite or Create React App  
- OpenWeatherMap API
